# 酒店运营系统 UI 原型

这是用于选择桌面端信息架构的抛砖型原型，不连接后端、不保存数据。

## 打开方式

直接打开：

```text
prototype/hotel-prototype.html
```

三套方案：

- `?variant=A`：值班控制台，房态矩阵优先
- `?variant=B`：宾客旅程，按入住流程分栏
- `?variant=C`：客房台账，高密度表格与详情面板

页面底部切换器或键盘左右方向键可以切换方案。点击“新建预订”等按钮会显示原型交互弹窗。

## 原型边界

- 仅桌面端
- 数据为虚构演示数据
- 不连接数据库或 API
- 不实现真实登录、权限、结算和备份
- 仅用于确认信息架构、页面密度和主操作路径

## 已确认方向

采用混合方案：

- 方案 A 作为主框架
- 方案 B 的今日时间线
- 方案 C 的右侧详情面板

其他结构保留为原型备选，不进入正式实现。
